# Security

## Supported versions

| Version | Supported |
|-|-|
| 0.2.x | Yes |
| below 0.2.0 | No (deprecated on npm) |

## Reporting a vulnerability

Vulnerabilities are reported privately through GitHub: **Security** tab of this repository, then
**Report a vulnerability**. Public issues are not used for security reports.

Fixes are released as a new version, and affected versions are deprecated on npm.

## Scope

The security model, covering what the packages enforce and what the integrating application handles,
is described in the [README](README.md#security-model).
